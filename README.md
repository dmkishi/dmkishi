Projects
-------------------------------------------------------------------------------
- [Moon Over Oakland](https://github.com/dmkishi/moon-over-oakland) is a Bluesky bot that posts the Moon's principal phases for Oakland, CA.
  - [Bluesky account](https://bsky.app/profile/moon-over-oakland.bsky.social)
- [Roaming Holiday Podcast Transcriptions](https://github.com/dmkishi/roaming-holiday-podcast-transcriptions) is a transcription website and builder for the Roaming Holiday podcast.
  - [Website](https://dmkishi.github.io/roaming-holiday-podcast-transcriptions/)
- [八千六百四十万ミリ秒 (Eighty-six Million Milliseconds)](https://github.com/dmkishi/eighty-six-million-milliseconds) is a Web-based millisecond clock expressed in Japanese numerals.
  - [Website](https://dmkishi.github.io/eighty-six-million-milliseconds/)
- [Moon Phases ICS](https://github.com/dmkishi/moon-phases-ics) is a subscribable calendar of moon phases.

Ancient
--------------------------------------------------------------------------------
- [Dusk2Dawn](https://github.com/dmkishi/Dusk2Dawn) is an Arduino library that calculates sunrise and sunset times.
- [NOAAWaterLevelCollector](https://github.com/dmkishi/NOAAWaterLevelCollector) is a Ruby script that fetches and aggregates water level data from the [NOAA CO-OPS API](https://tidesandcurrents.noaa.gov/api/).
- [Wave Tone](https://github.com/dmkishi/Wave-Tone) is a simple WebAudio toy responsive to device orientation.
- [Streams](https://github.com/dmkishi/Streams) one or more device orientation data to an external app such as [pd](https://puredata.info) or [Max](https://cycling74.com/products/max).
